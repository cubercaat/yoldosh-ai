# Chorraha — Android ilovasi

Capacitor qobig'i: ilova https://chorrahaa.uz ni ochadi (sayt yangilansa, ilovani qayta yig'ish shart emas).
APK GitHub Actions'da yig'iladi: `.github/workflows/android-apk.yml` (Actions → Android APK → Artifacts → `chorraha-debug-apk`).
Bu *debug* imzoli APK — sinov uchun (tanishlarga yuborish). Play Market uchun alohida imzolangan AAB kerak bo'ladi.
